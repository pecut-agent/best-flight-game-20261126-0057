Aurora Courier is a complete 2D pseudo-3D flight game that runs offline in the browser: chase-view flying over a coast, river, fields, forest and snowy peaks, gold target rings to thread in order, a lit runway to land on, full cockpit instruments (speed, altitude, climb, compass, throttle, fuel, damage), two delivery missions, generated WebAudio engine and wind sound, and judged landings from silk to hard arrival. Fly with arrows or WASD, set throttle with Shift and Ctrl, boost with Space, pause with P and restart with R; the mouse steers too.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8080 --directory game
```
